# **YBF Gerçeklik — Canonical Tanım**

**Kaynak**: `YBF_Algoritma_Tam_Dokuman.md` §1 \+ cross-axis matrix'leri (Gerçeklik × Onur/Saygı/Sınır/Özgürlük) \+ 12 kavramın Gerçeklik koordinatları.

## **1\. Temel Tanım (canonical §1, satır 41-53)**

**Gerçeklik \= Çevre / Doğa / Evren**

*"Bilincin dışında duran bir dekor değil; bilincin içinde oluştuğu zemindir, tüm arka alandır. Gerçeklik; Fizik, Kimya ve Biyoloji ile uyumludur"*

Kapsamı:

* İnsan bedeni  
* Zaman, ölüm  
* Ekoloji  
* Fizik ve kimya yasaları  
* Biyolojik ihtiyaçlar  
* Toplumsal çevre  
* Gezegen sınırları  
* Evrenin işleyişi

## **2\. Kritik İddia — Asimetri (yeni vurgu)**

*"İnsan bunları istediği gibi değiştiremez; Gerçeklik İnsanlığa, onura, saygıya, özgürlüğe ihtiyaç duymaz."*

**Bu tek cümle YBF'nin etik mimarisinin kalbinde**. Diğer 4 eksen (Onur, Saygı, Sınır, Özgürlük) insan bilincinin nitelikleridir — onlara birinin sahip çıkması gerekir. Gerçeklik **insandan bağımsızdır**. Bu asimetri:

* Diğer 4 eksen → korunabilir, geliştirilebilir, kaybedilebilir (öznel)  
* Gerçeklik → tanınır ya da inkâr edilir (nesnel)

## **3\. Gerçekliğin Üç İşlevi (canonical satır 49-51)**

```
1. Bilincin KALİBRASYON NOKTASI
   (öznel deneyim hangi nesnel zemine yaslanıyor?)

2. SINIRIN KAYNAĞI
   (sınır var çünkü gerçeklik sınırlıdır — Sınır ekseni Gerçeklik'ten doğar)

3. İnsan özgürlüğünün üzerinde yükseldiği MADDİ VE VAROLUŞSAL DAYANAK
   (Özgürlük havada değil — Gerçeklik zemini üzerinde inşa olur)
```

Bu, white paper §2.2'deki tek-satır key question ("Does it acknowledge…") çok ötesinde **mimari bir rol**: Gerçeklik diğer eksenlerin **kaynak ekseni**.

## **4\. Skorlama Mantığı (canonical satır 20-22)**

| Skor | Anlamı |
| ----- | ----- |
| `+1` | Pozitif Etki — Gerçekliği tanıyor, doğa/ekoloji/fizik yasalarıyla uyumlu |
| `0` | Nötr Etki — Gerçekliğe etki yok yada etkisi bilinmiyor. |
| `-1` | Negatif Etki — Gerçekliği inkâr ediyor, ekolojik/fiziksel/temporal zemini ihlal ediyor. Örnek: Çevreye zarar vermek, Doğaya zarar vermek, bu bağlamda yer alır. |

## **5\. Çapraz Eksen Mimari (canonical satır 356-386)**

Her eksen kombinasyonunun nitel tipolojisi var. Gerçeklik × diğer 4:

### **Gerçeklik × Onur**

|  | Onur VAR | Onur YOK |
| ----- | ----- | ----- |
| **Gerçeklik VAR** | 🟢 Kalibreli özgüven — gerçeğe kök salmış onur | 🟡 Depresif gerçekçilik — görüyor ama değer veremiyor |
| **Gerçeklik YOK** | 🟡 Narsistik fantazi — şişirilmiş, zemin yok | 🔴 İki kez kaybolmuş — ne kendini ne dünyayı |

### **Gerçeklik × Saygı**

|  | Saygı VAR | Saygı YOK |
| ----- | ----- | ----- |
| **Gerçeklik VAR** | 🟢 Ekosistem bilinci — hem öteki hem dünya gerçek | 🟡 Soğuk pragmatizm — dünyayı tanıyor ama insanı araç |
| **Gerçeklik YOK** | 🟡 Sentimental idealizm — sever ama gerçek görmez | 🔴 Tam yalıtılmışlık — ne ilişki ne zemin |

### **Gerçeklik × Sınır**

|  | Sınır VAR | Sınır YOK |
| ----- | ----- | ----- |
| **Gerçeklik VAR** | 🟢 En sağlam temel — tam kalibreli bilinç | 🟡 Gören ama duran — teorik, pratiksiz |
| **Gerçeklik YOK** | 🟡 Keyfi sınırlar — meşruiyetsiz dayatma | 🔴 Bilinç havada — manipülasyona en açık |

### **Gerçeklik × Özgürlük**

|  | Özgürlük VAR | Özgürlük YOK |
| ----- | ----- | ----- |
| **Gerçeklik VAR** | 🟢 **Bilim, sanat, icat** — sınırı tanıyarak içinde yol açıyor | 🟡 Analiz var sentez yok — gerçekçi ama hareketsiz |
| **Gerçeklik YOK** | 🟡 Zeminsiz yaratıcılık — kısa parlak, uzun çökmeli | 🔴 Tam yön yitimi |

**Anahtar gözlem**: Her satırda Gerçeklik VAR → diğer eksen için **bir basamak yukarı** yapısal duruma karşılık geliyor. Gerçeklik diğerlerinin nitelik çarpanı.

## **6\. Türetim Mimarisi — 12 Kavramın Gerçeklik Koordinatı**

Canonical doc, 12 ahlaki/duygusal kavramın hepsini Gerçeklik ekseniyle başlatıyor (satır 488-610). İşlevsel vs patolojik hal:

| Kavram | Gerçeklik VAR (işlevsel) | Gerçeklik YOK (patolojik) |
| ----- | ----- | ----- |
| Adalet | Gerçek ihlale dayalı, orantılı, onarıcı | Kurgusal ihlal → intikam kültürü |
| Güven | Gözlemlenebilir tutarlı davranış | Temelsiz idealizasyon / paranoya |
| Suçluluk | Gerçek zarar → ahlaki düzeltme sinyali | Zarar yok ama suçluluk — varoluş suçluluğu |
| Utanç | Gerçek değer ihlali, düzeltilebilir | Kimlik utancı — "varoluşum itibariyle yetersizim" |
| Korku | Gerçek tehdit → koruyucu alarm | Tehdit yok ama korku — paranoya, anksiyete |
| Manipülasyon | Gerçek bilgiyle yönlendirme (etik sorgulanır) | Gerçekliği çarpıtarak kontrol |
| Yaratıcılık | Gerçek kısıt içinde sürdürülebilir seçenek | Gerçeklikten kopuk fantezi |
| Sevgi | Gerçek kişiyi olduğu gibi tanıma | Hayali kişiye projeksiyon |
| Sadakat | Gerçek değer/kişiye, test edilmiş | Kurgu/manipüle edilmiş bağlılık |
| Mutluluk | Gerçek yaşantıya dayalı, sürdürülebilir | Kaçış mutluluğu, inkâr, uyuşturma |
| Umut | Gerçek potansiyele dayalı, eyleme döner | Kurgu, kaçış, derin hayal kırıklığı |
| Liyakat | Gerçek yetkinlik, ölçülebilir | Performans sanatı, sembol, torpil |

**Yapısal sonuç**: Bütün ahlaki/duygusal kavramların **patolojik formu Gerçeklik \= \-1**'den başlıyor. Gerçeklik kaybedildiğinde diğer eksenlerin doğru ölçümü imkânsızlaşıyor.
